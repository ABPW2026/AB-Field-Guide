A&B FIELD GUIDE PRO - DEPLOYMENT PACKAGE

This folder is a Progressive Web App (PWA).

Required next step:
1. Upload every file in this folder to the same HTTPS website folder.
2. Open that HTTPS address in Safari on iPhone.
3. Tap Share > Add to Home Screen.
4. Keep Open as Web App enabled, then tap Add.

Important:
- Do not install from the Microsoft file preview or Files preview.
- manifest.webmanifest, service-worker.js, index.html, and all PNG icons must remain together.
- Service workers require HTTPS (or localhost for development).
